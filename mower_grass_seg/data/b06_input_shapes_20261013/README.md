# B06 与 B07_v4 的固定图片对照

同一批 50 张原图和当前标注，原项目 Ultralytics 8.4.128 源码，本地 CPU PT 推理，conf=0.25、NMS IoU=0.7、retina_masks=True。未转换或部署 B06 NPU 模型。

| 指标 | B06 | B07_v4 |
| --- | ---: | ---: |
| 640x480 逐图平均 Mask IoU | 97.74% | 98.72% |
| 640x640 逐图平均 Mask IoU | 97.30% | 97.18% |
| 640x640 验证来源25张平均 IoU | 97.89% | 97.97% |
| 640x640 累计误检像素 | 157,272 | 120,581 |
| 640x640 累计漏检像素 | 51,806 | 48,964 |
| 018 方形输入 IoU | 97.70% | 47.52% |
| 000 方形输入 IoU | 60.17% | 98.38% |

640x640 下 B06 有15张优于B07_v4，35张较差。B06没有018的大面积前景水泥路误检，但000把绿色墙面和孔砖墙大面积识别为草坪。其平均IoU略高不代表误检更少：平均IoU给每张图相同权重，累计FP反映总误分面积，两种统计口径不同。

## 配置与数据差异

args.yaml 中，除实验名称和目录外，差异仅为 mosaic（B06=0.0、B07_v4=0.3）与 close_mosaic（0、80）。但训练数据并非相同快照，不能据此认定只改了Mosaic。

项目 TRAINING_LOG.md 记载 B06 用2799张训练图；B07_v4交付说明记载其使用2804张、多轮纠错标签、回补缺失标签及定向增强。故本次只能比较现有权重，不是严格Mosaic因果消融。指标参考的是当前标签，并非B06训练时历史标签。

## 查看结果

- `vs_b07_v4/018.jpg`：标注、B06、B07_v4，统一640x640，查看水泥路。
- `vs_b07_v4/000.jpg`：查看B06墙面误检。
- 预测面板绿色为正确草坪、红色为误检、蓝色为漏检。
- `comparisons/`：同一B06的两种输入尺寸对比。
- `vs_b07_v4/per_image.csv`：两个模型的逐图指标。
- `summary.json`：B06参数、版本、模型及样本哈希；`vs_b07_v4/summary.json`：汇总对比。

建议保留B07_v4默认部署，不根据018一张直接回退B06。若要判断关闭Mosaic是否能解决问题，应使用相同清洗数据和一致的固定方形验证条件进行受控训练。50张包含25张训练来源，不代表独立外场泛化。
