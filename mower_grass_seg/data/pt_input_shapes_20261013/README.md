# PT 输入尺寸与标注对照测试

2026-10-13，同一 PT 模型、同一批 50 张图片，对比宽 640 高 480 与补边后的 640x640 输入。本次仅执行本地 PT，没有修改或替换板端模型。

## 结果

以下指标以当前数据集标注为参考，按每张图全部 grass 实例的并集计算，不是三端输出一致性，也不是实例 mAP。

| 指标 | 640x480 | 640x640 |
| --- | ---: | ---: |
| 全部 50 张平均 Mask IoU | 98.72% | 97.18% |
| 训练集 25 张平均 Mask IoU | 98.74% | 96.40% |
| 验证集 25 张平均 Mask IoU | 98.70% | 97.97% |
| 最低单图 IoU | 91.23% | 47.52% |
| 像素累计 Precision | 99.15% | 98.28% |
| 像素累计 Recall | 99.64% | 99.30% |
| 累计误检像素 FP | 59,534 | 120,581 |
| 累计漏检像素 FN | 24,877 | 48,964 |

640x480 有 46 张 IoU 更高，4 张更低，分别为 024、027、028、037。最大下降是 024，约 0.85 个百分点。

018 的 IoU 从 47.52% 提升到 98.49%，前景大面积水泥路误检消失。044 从 87.47% 提升到 97.74%。剔除这两张后，其余 48 张仍平均改善约 0.32 个百分点。

## 对照条件

- 50 张原图均为宽 640、高 480，当前原图 SHA256 与之前三端实验记录逐一核对一致。
- 使用同一个原始 PT、同一 Ultralytics 标准后处理、CPU FP32、conf=0.25、NMS IoU=0.45、retina_masks=True。
- 640x480 条件不拉伸原图，不增加边框；640x640 条件上下各补 80 行，填充值为 114。
- 每次均检查实际送入模型的 tensor shape 和逐元素值，确认是对应图像的 RGB /255，不仅依赖 imgsz 参数。
- 标注来自对应 train/val 的 YOLO 分割标签。归一化多边形坐标乘以原图宽高、np.rint 取整、cv2.fillPoly 栅格化后合并；边缘指标受栅格化约定影响。
- 没有缺失标注；现有标注未在本轮逐像素人工复审。25 张为训练来源，25 张为验证来源，不替代独立外场测试。

## 查看结果

`comparisons/` 内每张图从左至右为现有标注、PT 640x480、PT 640x640。预测面板中绿色为正确草坪 TP、红色为误检 FP、蓝色为漏检 FN。左侧标注面板的绿色仅表示标注草坪。

`masks/` 保存原图尺寸的两组二值预测和标注 Mask；`per_image.csv` 保存 100 行逐图指标；`summary.json` 保存分组汇总、样本和模型校验值、环境版本。

## 后续决策

本批结果支持制作宽 640、高 480 的独立 NB 实验，并重新核对该尺寸下的 ONNX 输出形状、校准预处理与后处理索引。不能直接将旧 640x640 NB 去掉补边，也不能沿用旧版固定 anchor 数和原型尺寸。

目前结论仅针对 PT 对当前标注的表现。新尺寸的量化后精度、板端速度和实际摄像头效果仍需独立验证，默认部署保持不变。
