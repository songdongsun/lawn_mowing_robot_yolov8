## 第一轮微调方案

| 参数 | 本轮设置 | 说明 |
| --- | --- | --- |
| 初始化 | B08_v3_2 best.pt | 加载现有最佳模型，不覆盖原权重 |
| resume | False | 新实验，不恢复旧优化器/调度器进度；训练入口显式固定 |
| lr0 | 0.0001 | 原学习率的 1/10，保守起始值，不声称最优 |
| epochs / patience | 40 / 15 | 上限与早停，不保证达到上限或必然改善 |
| mosaic / close_mosaic | 0 / 0 | 原最佳轮位于关闭 Mosaic 阶段；首轮保留完整现场构图 |
| batch / imgsz / workers | 16 / 640 / 4 | 与原配置一致 |
| optimizer / seed / AMP | AdamW / 42 / False | 与原配置一致 |
| warmup_bias_lr | 0 | 防止偏置预热学习率脱离低学习率设置 |

其他参数使用当前训练入口及框架默认值。没有冻结骨干，没有额外重复或加权抽样。
训练集为原 2,804 张加困难 142 张，共 2,946 张；困难图约占 4.82%。
训练过程仍使用混合 val 1,199 张做早停和 best.pt 选择，结果偏重数量较大的旧验证集。
因此混合验证最优不等于困难场景最优，不能只依据混合 mAP 宣布微调成功。
