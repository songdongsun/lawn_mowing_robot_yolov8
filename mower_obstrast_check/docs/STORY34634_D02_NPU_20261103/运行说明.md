# D02 KL 唯一交付模型运行说明

当前只交付 `delivery_D02_KL/network_binary.nb`，根目录同名文件与其相同。80类方案已取消，历史试验不作为备选。

板端目录：`/root/d02_detect_static_20261103/delivery_D02_KL`。

静态复跑需使用独立工作目录，放入该模型、`detectStatic`、`input_list.txt`、`inputs/`，创建 `outputs/` 后运行：

```bash
LD_LIBRARY_PATH=/root/yolov8n_detect_npu_20260706/lib:$LD_LIBRARY_PATH ./detectStatic > board_run.log 2>&1
```

输入是已准备好的140张640×640 BGR uint8 PNG。主机等比例缩放并补边114，元数据记录原图宽高、缩放比例和left/top；模型内部完成RGB转换及/255，不重复归一化。

输出为原图坐标 `x1 y1 x2 y2 confidence class_id`，conf严格大于0.25，分类NMS IoU=0.7，最多300框。ID依次为人员、猫、狗、飞碟、运动球、玩具熊、软管、石头。

转换复现使用 `scripts/convert_npu.py attention_tail_kl`；八类评估使用 `scripts/evaluate_three_backends.py npu attention_tail_kl`。交付报告由 `scripts/make_report.py` 生成。
