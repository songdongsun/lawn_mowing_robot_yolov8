## 六 数据分析方法与结论

### 分析范围

本阶段全量分析发生在历史13类版本、68,849张图片与221,258框的快照上。检查图片可读取性、图片标签配对、五列格式、类别ID、坐标有效性、空标签、重复标签行、尺寸分布、字节重复及跨集合感知相似候选；目检六类新增train/val全部217张的总览、石块26张抽样及9对跨集合相似候选。

分析资料保留于 [dataset_analysis](../../../.p2-stage/dataset_analysis)，其中 [analysis.json](../../../.p2-stage/dataset_analysis/analysis.json) 为结构化统计，[review_conclusions.json](../../../.p2-stage/dataset_analysis/review_conclusions.json) 为审核结论，[visual_findings.json](../../../.p2-stage/dataset_analysis/visual_findings.json) 为具体样例。该历史分析不能冒充当前69,256张的全量视觉验收；交付时另做了当前集合数量复核和各次变更校验。

### 主要发现及处理状态

| 项目 | 分析发现 | 本阶段处理状态 |
| --- | --- | --- |
| 基础文件有效性 | 历史快照未发现读取失败、无效检测框、空标签或重复标签行 | 转换/合并持续执行格式与配对校验；不等于语义标签正确 |
| 精确重复 | train内10组完全相同图片，共22个文件，即12份冗余；10组标签文本均存在差异 | 未自动删除，需先核对并合并标注，不能直接去重丢标签 |
| 跨集合相似 | 9对候选经目检，其中4对COCO同图或近重复得到确认；其余5对未确认或为误报 | 未完成泄漏清理；不能宣称train/val完全独立 |
| 人员漏标 | 手推车、软管审核图中可见人员，但只有园艺类标签 | 已记录样例，未自动补标；猫狗也不能仅凭无标签判定不存在 |
| 类别冲突 | 铁锹与锄头存在相近目标或同源构图分到不同类别 | 已合并为spade_hoe；不表示其他错标已全部解决 |
| 软管边界 | 存在独立接头/喷头被作为garden hose的样例 | 仍需人工复核类别定义与样本去留 |
| 场景偏差 | 白底商品图、插画、强旋转、大目标居中图较多；石块抽样含裸岩地和大型景观石 | 做了草地合成实验，但不能替代真实低机位数据 |
| 原图独立性 | 石块train 189张对应63个文件名前缀组，每组3张；val 19组与其无相同前缀 | 记录增强来源，不把189张视为189个独立场景 |
| 负样本 | 历史快照没有空标签图，没有明确独立组织纯负样本 | 当前未新增纯负样本集；草地合成图已有目标，不算纯负样本 |

### 类别不平衡

历史分析时人员占train检测框的89.31%，新增六个园艺类别合计仅210个训练框。经过划分调整和增强，四个目标少数类达到每类120张训练图，但当前人员仍占训练框约 **89.15%**（189,685 / 212,773）。

本阶段缓解的是少数类参与训练的图片数量，不是彻底解决不平衡或外观覆盖。几十张原图衍生出的增强图依然相关，训练时需要结合每类召回率、误检和独立实景测试判断收益，不能因总图片数上升就认定识别可靠。

### 小目标与尺度

历史快照按640像素letterbox输入假设，统计框面积小于32×32像素的比例：

| 类别 | 小框数 / 该类总框数 | 比例 |
| --- | --- | ---: |
| sports ball | 3,930 / 5,051 | 约77.8% |
| frisbee | 927 / 2,572 | 约36.0% |
| person | 50,539 / 197,514 | 约25.6% |
| rock | 332 / 1,524 | 约21.8% |

园艺来源框的面积中位数约占原图53%～64%，明显偏向近景大目标，与远处草地小障碍物存在尺度差异。这些是图像像素尺度分析，不是实物尺寸或可检测距离；没有相机标定与距离真值，不能据此给出米级检测能力。
