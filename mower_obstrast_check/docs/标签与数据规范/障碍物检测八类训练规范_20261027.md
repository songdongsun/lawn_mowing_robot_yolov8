## 数据与标签处理要求

- 本轮不训练原 ID 6 `spade_hoe`（铲锄类）、7 `watering-cane`（浇水壶）、8 `wheel-barrow`（手推车）、9 `pruning-saw`（修枝锯）；原始数据留存追溯。
- 转换必须按原十二类 ID 一次性筛选并重映射，不能把新 ID 6、7 再当作旧铲锄类、浇水壶删除。同图保留所有八类目标的有效框，移除范围外类别框；坐标仍为五列 YOLO 检测格式 `class_id x_center y_center width height`，坐标归一化。
- 默认仅纳入含保留类别有效标注的图片，沿用原 train/val 划分。筛选后无有效框的图片不自动纳入八类训练集；若后续作为背景样本使用，须先确认没有漏标的八类目标。
- 训练配置须同步改为 `nc: 8`，`names` 按表中新 ID 排列；标签与配置必须成套使用。转换后核验图片标签配对、ID 范围、框坐标、分类统计与跨集合重复，重建对应标签缓存。
